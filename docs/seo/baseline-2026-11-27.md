# viza.it.com SEO baseline, 27 Nov 2026

Measured with `seo-optimizer/scripts/audit.mjs https://viza.it.com --max 200` (200 of 2,836 sitemap URLs) and curl.
The 25 Nov plan and research live in the untracked `docs/seo/` of the main checkout (SEO-PLAN.md and friends).

## Already in place

- One host, http 308 to https, HSTS preload. Unknown URLs return a real 404.
- robots.txt allows all crawlers, blocks `/api/` and `/s/`, lists the sitemap.
- Sitemap: 2,836 URLs with lastmod, 48 locales, hreflang cluster with x-default on every page.
- Googlebot, bingbot, OAI-SearchBot, ClaudeBot and PerplexityBot all get 200 and the real page (checked on /visa/japan).
- Geo redirect for CN, HK, MO and TW visitors in vercel.json skips crawlers and WhatsApp/Facebook scrapers.
- Home JSON-LD: Organization + TravelAgency, WebSite, FAQPage. GA4 G-RKJ1ZKV7QK and PostHog in the HTML.
- `/llms.txt` and `/index.md` serve real content.
- Link previews: a 1200x630 card per page and locale; the home card is now the photo collage with the white logo.

## Found and fixed in this pass

| Check | Before | Fix |
|---|---|---|
| favicon.ico | 404, no icon links at all | `app/favicon.ico`, `app/icon.svg`, `app/apple-icon.png` from the VIZA mark |
| Flag images | `<img>` with no alt on home, /visa and destination pages | `alt=""` (decorative, the country name is beside each flag) |
| Markdown for agents | `Accept: text/markdown` returned HTML | `/` with that header 307s to `/index.md` with `Vary: Accept` (the `<link rel="alternate" type="text/markdown">` was already there) |
| Discovery headers | none | `Link` header on `/` for index.md, llms.txt and sitemap.xml |
| robots.txt | no Content Signals, RSC payloads crawlable | `Content-Signal: search=yes, ai-input=yes, ai-train=yes`, `Disallow: /*?_rsc=` |
| security.txt | 404 | `/.well-known/security.txt` pointing at security@viza.it.com and /security |
| Search Console | domain verified by a VIZA Google account, not reachable from Kelin tooling | URL-prefix property verified for the Kelin GSC service account by HTML file |
| IndexNow | no key | key file in `public/`, changed URLs pinged after deploy |

## Left as is

- CJK titles and descriptions under the Latin length thresholds: normal for Chinese, Japanese and Korean.
- `id` and `ms` home titles are identical; they are different locales tied by hreflang.
- Card photos with `alt=""`: decorative, each card has its own text heading.
